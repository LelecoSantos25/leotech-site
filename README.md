# LeoTech Solutions

Site institucional da **LeoTech Solutions**: suporte técnico, redes e segurança digital em São Paulo e região.

🔗 **Site:** https://lelecosantos25.github.io/leotech-site/

## Sobre o projeto

Site de uma página, feito em HTML, CSS e JavaScript puros (sem framework), hospedado no GitHub Pages.

### Recursos

- Layout responsivo com menu para celular
- Modo claro e escuro (lembra a escolha e segue a configuração do aparelho)
- Português e inglês (botão PT/EN; link direto em inglês com `?lang=en`)
- Assistente virtual com respostas rápidas e atalho para o WhatsApp
- Formulário de contato via [FormSubmit](https://formsubmit.co/)
- Perguntas frequentes, formas de pagamento e Política de Privacidade (LGPD)
- Imagem de compartilhamento para WhatsApp e redes sociais
- Página 404 personalizada

## Estrutura

| Arquivo | Descrição |
| --- | --- |
| `index.html` | Página principal (HTML, CSS e JS no mesmo arquivo) |
| `404.html` | Página exibida quando um endereço não existe |
| `og-image.jpg` | Imagem que aparece ao compartilhar o link (1200×630) |

## Bibliotecas externas

- [Font Awesome](https://fontawesome.com/) – ícones
- [Google Fonts](https://fonts.google.com/) – fontes Poppins e Inter
- [particles.js](https://github.com/VincentGarreau/particles.js) – fundo animado
- [vanilla-tilt.js](https://micku7zu.github.io/vanilla-tilt.js/) – efeito 3D nos cards

## Como editar

1. Abra o `index.html` no GitHub e clique no ícone de lápis (✏️).
2. Faça a alteração e clique em **Commit changes**.
3. O GitHub Pages publica a nova versão em 1 a 2 minutos.
